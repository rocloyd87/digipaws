## Lessons
- A CONTINUE "remaining tasks" list can be a session or two stale: two of its five items were already
  built (matcher 145, FMP alerts) and one had been answered (HSBC). Read the live system (worktree, gas-v35,
  n8n credential list, workflow list) before building anything the list names.
- Telegram inline-button presses arrive as `callback_query` with no top-level `message`; any node that
  reads `$json.message.*` (Config, Owner Allowlist) must sit behind an `Is Callback` branch, and the
  trigger's `updates` change needs a deactivate/activate cycle to reach Telegram.
- n8n `noOp` nodes must carry `parameters: {}` — the API rejects the node without it.
